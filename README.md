# UGAF Studio

Universal Game QA Framework

## Features

- Desktop Capture
- Game Inspection
- Pixel Inspector
- OCR
- Template Matching
- Automation
- Reporting

## Requirements

- Python 3.14
- Windows 11

## Installation

pip install -r requirements.txt

## Run

python main.py

## Quality

pre-commit run --all-files

pytest

## Project Structure

app/ capture/ controllers/ core/ gui/ input/ vision/ automation/ tests/
