# Codex Execution Brief — UGAF Studio

เอกสารนี้เป็น handoff สำหรับให้ Codex ลงมือทำตามลำดับ ไม่ใช่คำสั่งให้เปลี่ยนทุก subsystem ในครั้งเดียว ให้อ่านคู่กับ [`roadmap-autonomous-game-qa.md`](roadmap-autonomous-game-qa.md) และตรวจ implementation ปัจจุบันก่อนเริ่มแต่ละ work package

## Product constraints

- เป้าหมายแรกคือ Windows desktop QA สำหรับ Unreal Engine/FMV โดยเกมตัวแรกคือ HighSchoolBloodDemo; เพิ่มเกม/แนวผ่าน profile และ adapter contracts
- Google Sheets/Docs/website เป็น read-only source; การนำเข้าต้องรักษา source URL, ID, revision/hash, sheet, row และเวลา sync
- SQLite ต่อ game profile เป็นข้อมูลหลัก; Obsidian เป็น export/projection ที่สร้างซ้ำได้ ห้ามทำสำเนาที่แก้ไขแยกจนกลายเป็นฐานจริงอีกชุด
- ห้าม auto-accept EULA/privacy, credentials, purchase, delete/reset save หรือ choice ที่ไม่มี expected behavior ที่อนุมัติไว้
- ใช้ผล `PASS` เฉพาะเมื่อ assertion ผ่านพร้อม evidence และระบุ profile/build/source revision; ใช้ `BLOCKED`, `NOT_RUN` หรือ `NEEDS_REVIEW` เมื่อไม่มีหลักฐานพอ
- Run ที่ส่ง input เกมมี budget, stop control, manifest, trace และ cleanup; มี game-input controller ได้ครั้งละหนึ่งตัว
- แยก code/mock test, safe preflight และ live game run ให้ชัด อย่าอ้างว่าเกมจริงผ่านจากการผ่าน unit test

## ช่องว่างที่ควรแก้ก่อน

1. **Agent fail-safe/cache promotion:** `VLMAgent` และ live loop มี parsing/cache/outcome หลาย seam; ตรวจว่า output อยู่ใน schema/allowlist/bounds ก่อน execute และไม่ใช้ syntactic validity หรือ frame-difference เป็น QA pass
2. **Source traceability/idempotency:** importer เก็บ raw sheet snapshots ได้ แต่ flow edges ที่ upsert เข้า story graph ไม่มี source owner/revision เพียงพอสำหรับลบหรือทำเครื่องหมาย stale เมื่อชีตเปลี่ยน; localization priority อาจเลือกค่าโดยไม่เก็บ conflict ที่ reviewer ต้องเห็น
3. **Runtime replay:** กำหนดสัญญากลางของ run/event/evidence เพื่อให้รายงาน replayable; screenshot/video/audio files เก็บเป็น artifacts ที่มี hash/path ไม่เก็บ BLOB หนักใน SQLite
4. **Memory history:** `game_memory` แบบ key-value ปัจจุบันเหมาะกับ fact ล่าสุด แต่ยังเก็บประวัติการเปลี่ยน, validity/build scope และ reviewed status ไม่ครบ; เพิ่มแบบ additive และ migration-safe
5. **UE state access:** ไม่มี universal state detector; ออกแบบ black-box adapter ก่อน และเสนอ Unreal dev-only bridge เป็น option สำหรับ scene ID, playback timecode, subtitle key, option IDs/timer และ minigame state
6. **Build/runtime:** ทดสอบ frozen worker launch, current directory, DB seed/migration, model/tool prerequisites, report paths และ upgrade preservation ไม่ใช่แค่ process start
