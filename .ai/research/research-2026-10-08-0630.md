## 2. Collaboration Prior Tracking Design

### 2.1 What to Track
- **Agent pairs**: Which agents successfully collaborate
- **Task types**: Which task types succeed with which agent combinations
- **Handoff quality**: Success rate of agent-to-agent handoffs
- **Execution time**: Time taken for successful collaborations
- **Error patterns**: Common failure modes in agent collaborations

### 2.2 Data Model
```python
class CollaborationPrior(BaseModel):
    task_type: str
    source_agent: str
    target_agent: str
    success_count: int
    failure_count: int
    avg_execution_time: float
    last_used: datetime
    success_rate: float  # Computed: success_count / (success_count + failure_count)
```

### 2.3 Storage
- SQLite database for persistence
- In-memory cache for fast access
- Periodic aggregation and cleanup

### 2.4 Usage
- Query collaboration priors before task dispatch
- Prefer agent pairs with high success rates
- Avoid known failure patterns
- Suggest optimal agent combinations
